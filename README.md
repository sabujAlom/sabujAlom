### 🏋️ GymNest — Fitness & Gym Management Platform
[![Live](https://img.shields.io/badge/🌐_Live_Site-22c55e?style=flat-square)](https://gymnest-client-k88v.vercel.app/)
[![Client](https://img.shields.io/badge/Client_Repo-181717?style=flat-square&logo=github)](https://github.com/kouser-ahamed/gymnest-client)
[![Server](https://img.shields.io/badge/Server_Repo-181717?style=flat-square&logo=github)](https://github.com/kouser-ahamed/gymnest-server)

> A role-based fitness and gym management platform with class booking, trainer management, community forum, and Stripe payment integration.

**Tech Stack:** `Next.js` `React.js` `Node.js` `Express.js` `MongoDB` `Tailwind CSS` `Better Auth` `JWT` `Stripe`

- 🔐 JWT HTTPOnly cookie sessions and Google OAuth via Better Auth with protected role-based routes
- 💳 Stripe Checkout integration for class bookings with duplicate prevention and full transaction history
- 📊 Three distinct dashboards (Member, Trainer, Admin) with Recharts analytics and forum moderation
- 🔇 Soft-block system enforced on both frontend and backend
- 🔍 MongoDB `$regex` search, category filtering, and server-side pagination
